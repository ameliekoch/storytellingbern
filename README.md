# Storytelling Bern

A lightweight, responsive static website for a Story Slam event series.

## Files
- `index.html` — homepage
- `events.html` — upcoming and past events
- `about.html` — storytelling explanation and resources
- `contact.html` — contact information
- `styles.css` — visual design

## Before publishing
1. Replace the placeholder event titles, dates, venues and themes in `events.html` and the homepage.
2. Replace the placeholder name, email and phone number in `contact.html`.
3. Replace the abstract event-photo blocks with your own event photos if desired.
4. Upload the files to the hosting provider for `storytellingbern.ch`.

The About page links to The Moth's current storytelling resources.
